# pyspark-hive-example

Examples demonstrating how to interact with Hive tables using PySpark.

## Examples
- `src/pyspark-write-hive-table.py`: Create a Spark session with Hive support and write a managed table.
- `src/pyspark-read-hive-table.py`: Read from an existing Hive table using the DataFrame API and SQL.
- `src/pyspark-save-table-from-temp-view.py`: Save data from a temporary view into a Hive table.
- `src/pyspark-hive-partitioned-table.py`: Create and query a partitioned Hive table stored in the default warehouse.
